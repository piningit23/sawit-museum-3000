A museum-label generator for the year 3000: `main.py` writes one fixed, deterministic museum label (104 characters, one line) to `/output/entry.txt` — the deadpan label a museum in the year 3000 puts beside a stapler, read by curators who concluded humans pinned dead trees together so the trees could not leave — with a built-in guard that refuses to write unless the text is one line and 1–200 characters.

## Run it

```sh
python3 main.py
```
